# Mini Shell OS

**Mini Shell OS** is a lightweight Unix-like command-line shell developed for educational purposes. It demonstrates core shell functionalities such as command parsing, execution, and process management.

---

## ✨ Features
- Execute both **built-in** and **external commands**
- Support for **input/output redirection**
- **Command pipelining** (`|`)
- Basic **job control**
- **Customizable prompt**
